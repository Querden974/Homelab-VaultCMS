## Qu'est-ce que Passbolt ?

Passbolt est un gestionnaire de mots de passe open source basé sur le chiffrement OpenPGP, conçu à l'origine pour un usage en équipe. Il permet de stocker, organiser et partager des identifiants de façon sécurisée, via une extension de navigateur ou une application mobile.

## Rôle dans mon homelab

Passbolt centralise l'ensemble de mes identifiants (accès aux applications de mon homelab, comptes personnels, clés d'API...) dans un coffre-fort que j'héberge moi-même, plutôt que de faire confiance à un gestionnaire de mots de passe cloud tiers.

## Fonctionnalités clés

- Chiffrement des données basé sur OpenPGP
- Partage sécurisé d'identifiants entre utilisateurs et groupes
- Extension de navigateur pour le remplissage automatique
- Application mobile dédiée
- Gestion fine des permissions d'accès aux mots de passe
