## Qu'est-ce qu'Immich ?

Immich est une solution open source de sauvegarde et de gestion de photos et vidéos, pensée comme une alternative auto-hébergée à Google Photos. Elle propose une application mobile qui sauvegarde automatiquement les médias du téléphone vers le serveur, ainsi qu'une interface web complète pour les consulter et les organiser.

## Rôle dans mon homelab

Immich me permet de reprendre la main sur mes photos et vidéos personnelles, sans dépendre d'un service cloud tiers ni de ses conditions d'utilisation. Toutes mes sauvegardes restent hébergées chez moi, sur mon propre matériel.

## Fonctionnalités clés

- Sauvegarde automatique depuis une application mobile (Android/iOS)
- Reconnaissance faciale et recherche par intelligence artificielle
- Partage d'albums et de photothèques entre plusieurs utilisateurs
- Gestion multi-utilisateurs
- Interface web moderne, proche de l'expérience Google Photos
